# 穿衣人偶结构原型

[English](dressed-doll-design.en.md) · [文档索引](README.md)

本入口用于设计有头发、帽子、衣物、手脚和包袋的人偶。它按人工选型与尺寸生成可复核的
部件步骤，不是照片自动识别、原作针法恢复或已验证的完整复刻。现有照片路径与 G3/G4
门槛未改变；旧图解、工程和试钩包继续使用原格式。

当前构造没有达到复杂参考作品的结构还原要求。后续按
[复杂构造推进路线](construction-roadmap.md)先补工序表达。已另设“人工工序图解（校验与阅读）”入口，
读取人工录入的复杂工序；本页的选型生成器尚未自动使用这些新工序。

## 在应用中使用

打开「手动输入」，在页面下方展开「穿衣人偶结构原型（新增）」。

1. 选择「宽檐帽·卷发·连衣裙」或「翻边帽·长发·短外套与裙层」作为起始结构。
2. 填目标总高和本原型使用的针/行密度。默认 24cm、22 针/28 行只是设计输入；
   须用实际线与针分别做圈钩、片钩和肋纹小样，不能把默认值登记为实测。
3. 在「调整关键轮廓与构造」中改头径、掌腕、鞋底、上衣长度、发束和帽子选型。
   头径、掌腕、鞋底和上衣长度按目标总高的比例给出，并随总高变化；手改过的保持所填数值，
   页面会列出哪些已手改，点「恢复为按总高比例的尺寸」可回到比例值。
   点「生成穿衣人偶结构原型」。部件表展示各自钩法与分段，连接图展示装配去向。
4. 下载设计参数 JSON、结构方案 JSON、逐部件 Markdown；需要打印时点「准备结构原型 PDF」。
5. 修改参数后，旧原型仍保留用于查看，下载会停用；重新生成后才下载新版本。

完整尺寸和选型保存在设计 JSON。可在本机修改后用「载入设计 JSON」重新生成。
没有新增云端模型、照片上传或自动配色推断。连接图仅表示装配关系，不是外观渲染或成形仿真。

## 当前构造能力

| 结构 | 明确表达的内容 | 仍须确认 |
|---|---|---|
| 头身 | 独立头部；下身、腰、胸肩和颈段 | 填充后的轮廓、支撑、总高 |
| 帽子 | 帽身与宽檐；或独立片钩 BLO 翻边 | 戴上发帽后的围度、帽檐平整度、肋纹密度 |
| 头发 | 发帽、长发束与短刘海；直发或加针回钩卷发 | 自然垂长、卷曲程度、摆放密度 |
| 手臂 | 手掌—手腕—前臂围度转折 | 掌腕轮廓；尚无拇指和独立手指 |
| 鞋靴 | 锁针双侧起椭圆底；鞋头优先减针，再收鞋跟和鞋口 | 鞋底长宽、左右朝向、腿段与鞋口的配合 |
| 衣服 | 整片与开襟片；肩缝和领口针位、袖窿行边、独立开放袖筒 | 片钩与圈钩的密度差、领口与袖窿的实际合身 |
| 裙子 | 独立开放裙层，分别记录腰围与展开 | 锁针环松紧、层间余量和固定方式 |
| 包与装饰 | 折叠袋身、包盖、背带；可选分片花瓣与花心 | 厚度、落点、配件和原作纹理差异 |

身体的平钩圈数按两种高度估算的中间值对齐目标高度：一种每圈都按行高计，一种对加减针圈只计
竖直部分。两个估算都写在身体的试合说明里，都不是实测，须钩好填棉后量。裙层的加针位置逐圈
错开，不再集中在同一列；鞋头、鞋跟等有明确塑形位置的部件不变。发帽的装配说明按发帽圈数和
头部眼位圈生成：圈数不少于眼位圈时，改为提示向后倾斜并用珠针试戴，不再写“放在眼位上方”。

衣物先留袖窿再缝侧边；输出会给出每侧需留的行边数、肩缝针数及领口剩余针数。
袖筒针数与衣片行边数不是同一单位，缝合须按长度分段分配。若衣片短到容不下袖窿，
生成会报错，要求增加上衣长度或调整掌臂围度，不会静默缩小袖窿。

## 命令行与文件边界

```bash
# 从当前源码直接运行；无需先安装新 console entry point
python -m app.doll_cli --starter wide_brim_curls \
  --out-dir trial_outputs/dressed-wide-brim --pdf
python -m app.doll_cli --starter folded_cap_layers \
  --out-dir trial_outputs/dressed-folded-cap --pdf

# 修改导出的 design.json 后重新生成，使用新目录
python -m app.doll_cli --design trial_outputs/dressed-wide-brim/design.json \
  --out-dir trial_outputs/dressed-wide-brim-revised --pdf
```

安装当前源码后也有 `crochet2pattern-doll` 命令。`--pdf` 需要已有的可选 `pdf` 依赖。
输出目录包含 `design.json`、`plan.json`、`plan.md`、`assembly.dot`，选择 PDF 时另有 `plan.pdf`。
不覆盖已有同名文件；任一参数或可选导出失败时不会先写出一半方案。

设计格式为 `dressed-doll-design-v1`，结构格式为 `dressed-doll-plan-v1`。
它们不是旧版 PatternResult、工程文件或试钩 ZIP，不能在旧试钩入口当作已绑定图解导入。
当前原型的制作结果先保留独立照片和部件修改记录，不冒充原有 G4 校准证据。

## 自检证明什么

- 起针分为魔法环、锁针起环、片钩起链和双侧椭圆起链。
- 片钩首行跳过第一个锁针；后续短针翻转锁针不计入工作针目。
- 每一步操作式完整消耗前一步工作针目，声明针数须等于实际产出；椭圆首圈另核对两端及双侧工作边。
- 锁针与翻转链计入工作量统计，但不混入下一行的工作针数。不据此估算克重或工时。
- 装配引用须存在、不可成环，所有非根部件都须有去向。
- 导出重新校验模型；JSON 不能把 `unverified_prototype` 改成实钩通过状态。

这些检查不证明布料平整、服饰合身、原作还原度或实际可钩性。本版仍主要使用短针及加减针；
竖向条纹、复杂花瓣、拇指、扣眼、混合针高与原作可能使用的棒针或片材工艺没有自动复刻。
必须对照完整参考作品审查，不能用成功钩出一个头或一只手替代整件相似度验收。

## 技法依据与设计假设

基础短针、起链与翻转规则核对了 [Craft Yarn Council 的读图说明](https://craftyarncouncil.com/standards/how-to-read-crochet-pattern)
和 [PlanetJune 的基础针法教程](https://www.planetjune.com/blog/amigurumi-help/crochet-basics-right-handed/)。
锁针双侧起椭圆的构造原则参考作者自己的 [Shiny Happy World 椭圆教程](https://www.shinyhappyworld.com/2018/02/how-to-crochet-oval-amigurumi.html)。
本仓的参数化圈数、帽檐加针、鞋头/鞋跟分配、发束和衣片组合是原型设计假设，
不是这些来源对本图解的验证，也未复制任何完整玩偶图解。
